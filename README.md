# Typing Game

A typing game platform where users can practice their typing skills racing alongside others. Built with Vue and Express.

## Features

- Real-time multiplayer typing game
- Google OAuth2 authentication
- User statistics and leaderboards

## Installation

### Prerequisites

Ensure the following software is installed:
- [Node.js](https://nodejs.org/)
- npm

### Cloning the repository

  ```bash
  git clone https://github.com/ashahnami/typing-game.git
  cd typing-game
  ```

Navigate to both the `backend` and  `frontend` folders and  install the npm dependencies by typing  the following command:

```bash
npm install
```

### Usage

Run the following in both the `backend` and `frontend` folders to start the application:

```bash
npm start
```

The web browser should automatically open to: [http://localhost:5173/](http://localhost:5173)
